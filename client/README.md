### 🎨 Overview
This directory contains the user interface for UrbanKart. It acts as the interactive portal for consumers and vendors, consuming the intelligent NoSQL APIs provided by the backend.

### 🧩 Component Architecture
The frontend is built with modularity and reusability in mind:
- **`/components`**: Reusable UI elements (Buttons, Cards, Modals).
- **`/pages`**: Full-screen views mapped to routes (Home, Product, Cart, Checkout).
- **`/context`**: React Context providers for global state (Auth, Cart).
- **`/hooks`**: Custom React hooks for API data fetching and state management.
- **`/assets`**: Static files, images, and global stylesheets.
