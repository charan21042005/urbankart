### 📋 Overview
This directory serves as the central hub for all non-code documentation, planning artifacts, and academic specifications for the UrbanKart project.

### 📁 Contents
- **Planning Documents:** Roadmaps, SRS (Software Requirements Specification) blueprints, and feature lists.
- **Database Schemas:** Diagrams and rationales for MongoDB document structures (Embedding vs. Referencing).
- **API Blueprints:** REST endpoint definitions and payloads.
- **Academic Context:** Notes bridging practical implementation with CSE494 theoretical concepts.

### 🔍 Guidelines for Contributing
- Keep documentation up-to-date with codebase changes.
- Ensure architectural decisions include a "Why" section explaining the NoSQL tradeoffs.
